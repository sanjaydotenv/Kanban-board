# 🗂️ Kanban Board

A simple and responsive **Kanban Board** built with HTML, CSS and JavaScript.

This is one of my JavaScript projects where I practiced **DOM manipulation, Drag & Drop, Local Storage and responsive UI**.

---

## ✨ Features

* ➕ Add new tasks with title and description
* 🖱️ Drag & drop tasks between columns
* 🗑️ Delete tasks
* 🔢 Automatic task count
* 💾 Save tasks using Local Storage
* 🌙 Dark / Light mode
* 📱 Responsive design
* ⚡ No external framework required

---

## 📌 Columns

The board has three simple stages:

| Column         | Purpose                         |
| -------------- | ------------------------------- |
| 📝 To Do       | Tasks that need to be done      |
| 🔄 In Progress | Tasks currently being worked on |
| ✅ Completed    | Finished tasks                  |

You can drag a task from one column and drop it into another.

## 💡 How It Works

### ➕ Creating a Task

Click **Add New Task**, enter the title and description, and create the task.

The new task is added to the **To Do** column.

### 🖱️ Drag & Drop

Tasks can be dragged between:

`To Do → In Progress → Completed`

The task's new position is saved automatically.

### 💾 Local Storage

Tasks are stored in the browser's Local Storage.

So even after refreshing the page, your tasks are still there.

### 🌙 Theme

The board supports both **Dark Mode** and **Light Mode**.

The selected theme is also saved, so it stays the same after refreshing.
